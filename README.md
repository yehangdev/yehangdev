# 夜航

平时写一些小型的后端和数据工具，主要使用 Java、Go 和 Python。

## 关注方向

- 应用日志处理
- Redis 诊断与缓存行为
- 配置校验与漂移检查
- 基于 SQL 的内部服务

## 项目

- [Cardinal](https://github.com/yehangdev/Cardinal)：Redis 命令行诊断工具
- [Kindling](https://github.com/yehangdev/Kindling)：JSONL 日志过滤、分组和汇总工具
- [Driftwood](https://github.com/yehangdev/Driftwood)：配置比较与漂移检查 CLI

仓库大多是一些命令行工具或聚焦型服务，用来解决日常后端工作中的具体问题。
